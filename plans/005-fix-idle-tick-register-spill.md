## 1. Why this plan exists

Plan 004 made the loaded tick much cheaper (4 active slots, none due:
~425 → ~135 cycles) but made the **idle** tick more expensive: ~88 → ~117
cycles, about +33%.

The cause is not the algorithm. It is that `async_delay_tick()` now declares
three register locals (`_ad_now` as a 16-bit pair, `_ad_m`, `_ad_fired`), so
CodeVisionAVR spills them on entry and reloads them on exit — **before** the
function has even looked at the mask, and on **every** tick including the ones
that return immediately.

From `Debug/List/async_delay_test.asm` at `4a0224c`:

```asm
_async_delay_tick_G000:
	RCALL __SAVELOCR4        ; <-- 15 cycles, paid before anything is decided
;	_ad_now -> R16,R17
;	_ad_m -> R19
;	_ad_fired -> R18
	LDS  R30,__async_tick_counter_G000
	...
	LDS  R19,__async_active_mask_G000
	CPI  R19,0
	BREQ _0x2020005          ; idle exit
	...
_0x2020005:
	RCALL __LOADLOCR4        ; <-- 15 cycles
	ADIW R28,4
	RET
```

`__SAVELOCR4` is `ST -Y,R19 / ST -Y,R18 / ST -Y,R17 / ST -Y,R16 / RET`
(4 × 2 + 3 for the RCALL + 4 RET ≈ 15). `__LOADLOCR4` is the mirror. That is
**~30 cycles of pure overhead on every tick**, idle or not.

Pre-004 the tick had a single local (`unsigned char m`), which CVAVR handled
with a plain `ST -Y,R17` / `LD R17,Y+` pair — 4 cycles.

This regression did not show up in the user's Proteus run because
`async_delay_test.c` keeps all 4 slots busy at all times, which is exactly the
scenario that got 68% faster. For an application that arms a delay only
occasionally, idle is the common case.

## 4. Design

Two independent changes. Both are pure code-shape; neither touches state
transitions, the wrap-safe test, the masks, or the API.

### 4.1 Split the fast path from the walk

Put the early-exit path in a function with **no locals at all**, so CVAVR has
nothing to spill, and move the register-hungry walk into a separate function
that is only called when a slot is genuinely due.

```c
static void async_delay_tick(void)      /* no locals -> no SAVELOCR */
{
    _async_tick_counter++;
    if (_async_active_mask == 0)
        return;
    if (!_ASYNC_REACHED(_async_tick_counter, _async_next_target))
        return;
    _async_delay_tick_walk();
}
```

`_async_delay_tick_walk()` keeps the unrolled `_AD_TICK_SLOT` chain and pays
the spill only on the rare ticks where something expires.

Two consequences to accept knowingly:

1. **`_async_tick_counter++` on a volatile instead of a hoisted local.**
   Pre-004 the code did exactly this, so it is not new. The counter is read
   again by the gate compare and once more inside the walk — 2 extra `LDS`
   pairs (~8 cycles) on the *loaded* path, in exchange for ~30 cycles on
   *every* path. Net win unless a slot expires on almost every tick, which
   would mean a delay of 1–2 ticks (pathological).

2. **`_ad_now` inside the walk must be read once into a local there**, or the
   per-slot volatile re-read comes back (that was one of 004's wins). Read it
   at the top of `_async_delay_tick_walk()`.

CVAVR emits `RCALL` for a same-module static call, so the extra call costs 3
cycles in + 4 out on the loaded path only.

### 4.2 Drop `_ad_fired` entirely

`_ad_fired` exists to skip `_async_recompute_next()` when nothing expired. But
under `ASYNC_DELAY_OPT_NEXT_TARGET`, reaching the walk **already proves**
something is due:

- `_async_next_target` is always the exact minimum of the ACTIVE targets:
  `start()` takes the min unconditionally, `cancel()` does a full recompute,
  and the walk recomputes after expiry (ARCHITECTURE.md §6.4).
- The walk is entered only when `_ASYNC_REACHED(now, _async_next_target)`.
- Therefore at least one ACTIVE slot has `target == _async_next_target` and
  satisfies the same test → at least one `_AD_TICK_SLOT` fires.

So the recompute is unconditional inside the walk. That removes one local, one
`LDI`, one `CPI`/`BREQ`, and the `_AD_MARK_FIRED()` macro pair.

**This argument is a speed optimization, not a correctness requirement** — an
unconditional `_async_recompute_next()` is correct either way (it is O(N) and
idempotent). If you doubt the reasoning, keep the call unconditional anyway;
never make it conditional on something weaker.

Fewer locals in the walk may also drop it from `__SAVELOCR4` to
`__SAVELOCR3`/`R2` — a bonus, not the point.

### 4.3 Explicitly NOT in scope

- Do **not** flip `ASYNC_DELAY_DEFERRED_CALLBACKS` to 1. It removes the ISR's
  `ICALL` and would cut the 11-register ISR spill (idle ~117 → ~32), but it
  changes *when* callbacks run. That is the user's call, separately.
- Do **not** add the lowest-set-bit LUT or hand-written ASM (rejected in
  plan 004 §7.4, for reasons that still hold).
- Do **not** touch the masks, `_ASYNC_REACHED`, the phase-locked
  `target += duration`, the SREG critical sections, or `expire_slot`.
- Do **not** "simplify" the counter increment to sit after a return.

### Phase 2 — Rewrite the tick

Replace `async_delay.h:757`–`884` (the `_AD_MARK_FIRED`/`_AD_TICK_SLOT` macro
block plus `async_delay_tick()`) with:

```c
#if ASYNC_DELAY_OPT_UNROLL_TICK
// Per-slot tick body. `n` MUST be a compile-time constant so that (1<<n),
// ~(1<<n) and &_async_slots[n] all fold to literals / absolute addresses.
// With a runtime index CodeVisionAVR emits RCALL __LSLW12 (a bit-at-a-time
// shift loop) for (1<<i), a MUL for the i*sizeof struct offset, and
// RCALL __GETW1P to load .target - ~72 cycles per slot instead of ~13.
// Do NOT introduce a runtime-indexed caller; it silently undoes all of it.
#define _AD_TICK_SLOT(n)                                                      \
    if (_ad_m & (unsigned char)(1 << (n)))                                    \
    {                                                                         \
        if (_ASYNC_REACHED(_ad_now, _AD_TARGET(n)))                           \
            _async_delay_expire_slot((unsigned char)(n),                      \
                                     (unsigned char)~(1 << (n)));            \
    }
#endif

#if ASYNC_DELAY_OPT_BITMASK
// Walk the ACTIVE slots and expire the ones that are due.
// Split out of async_delay_tick() on purpose: this is where the register
// locals live, so CodeVisionAVR's __SAVELOCR spill is paid ONLY on the ticks
// that actually have work, not on every idle tick.
// ISR context - interrupts are already off.
static void _async_delay_tick_walk(void)
{
    async_tick_t  _ad_now;
    unsigned char _ad_m;

    _ad_now = _async_tick_counter;   /* once: keeps the volatile out of the
                                        per-slot compares */
    _ad_m   = _async_active_mask;

#if ASYNC_DELAY_OPT_UNROLL_TICK
    _AD_TICK_SLOT(0)
#if ASYNC_DELAY_MAX_SLOTS > 1
    _AD_TICK_SLOT(1)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 2
    _AD_TICK_SLOT(2)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 3
    _AD_TICK_SLOT(3)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 4
    _AD_TICK_SLOT(4)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 5
    _AD_TICK_SLOT(5)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 6
    _AD_TICK_SLOT(6)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 7
    _AD_TICK_SLOT(7)
#endif
#else
    // Not unrolled: runtime bit scan. Kept so the unroll can be A/B measured.
    {
        unsigned char i;
        for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
        {
            if (_ad_m & (unsigned char)(1 << i))
            {
                if (_ASYNC_REACHED(_ad_now, _AD_TARGET(i)))
                    _async_delay_expire_slot(i, (unsigned char)~(1 << i));
            }
        }
    }
#endif

#if ASYNC_DELAY_OPT_NEXT_TARGET
    // Unconditional: reaching this function means the earliest target was
    // reached, so at least one slot fired and the cached minimum is stale.
    // (Also correct even if none had - the recompute is idempotent.)
    _async_recompute_next();
#endif
}
#endif

// MUST be called from timer ISR at exactly ASYNC_DELAY_TICK_HZ rate.
// Increments the tick counter, then returns as fast as possible unless a slot
// is actually due. WARNING: callbacks execute in ISR context - keep them very
// short! (unless ASYNC_DELAY_DEFERRED_CALLBACKS=1, see async_delay_poll)
static void async_delay_tick(void)
{
#if ASYNC_DELAY_OPT_BITMASK && ASYNC_DELAY_OPT_SPLIT_TICK
    // NO locals in this function, deliberately: CodeVisionAVR spills register
    // locals with RCALL __SAVELOCR4 on entry and __LOADLOCR4 on exit, ~30
    // cycles paid on EVERY tick - including the idle ones that return three
    // instructions later. All the locals live in _async_delay_tick_walk().

    // Counter FIRST, always. Every early return below must not skip it or
    // delays drift whenever no slot happens to be active.
    _async_tick_counter++;

    if (_async_active_mask == 0)
        return;                     // idle tick

#if ASYNC_DELAY_OPT_NEXT_TARGET
    // Nothing due yet: one wrap-safe compare and out, regardless of how many
    // slots are active. This is what makes the tick O(1).
    if (!_ASYNC_REACHED(_async_tick_counter, _async_next_target))
        return;
#endif

    _async_delay_tick_walk();
#elif ASYNC_DELAY_OPT_BITMASK
    /* SPLIT_TICK=0: the single-function shape from plan 004. */
    _async_tick_counter++;
    if (_async_active_mask == 0)
        return;
#if ASYNC_DELAY_OPT_NEXT_TARGET
    if (!_ASYNC_REACHED(_async_tick_counter, _async_next_target))
        return;
#endif
    _async_delay_tick_walk();
#else
    // Legacy: full linear scan (behavior identical to before when all flags 0).
    unsigned char i;
    async_tick_t  _ad_now;
    _ad_now = (async_tick_t)(_async_tick_counter + 1);
    _async_tick_counter = _ad_now;
    for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
    {
        if (_AD_STATE(i) == ASYNC_SLOT_ACTIVE)
        {
            // Wrap-safe "now is past target" test: if (tick - target) < half
            // the range, the delay has elapsed. Stays correct across a 16/32-bit
            // counter wrap as long as the delay is shorter than half the range.
            if (_ASYNC_REACHED(_ad_now, _AD_TARGET(i)))
                _async_delay_expire_slot(i, (unsigned char)~(1 << i));
        }
    }
#endif
}
```

Note the `#elif` arm is byte-identical to the `#if` arm here — that is because
the split is what the flag gates and the *body* is the same either way once the
walk is a separate function. **If that bothers you, collapse them into one arm
and drop the flag** — but then say so in your report, because the plan promised

## 10. Maintenance notes

- **The CVAVR fact worth remembering**: register locals are spilled at function
  *entry*, before any branch. A hot function with a cheap early-exit path must
  therefore keep that path in a local-free function and push the registers into
  a callee. This will apply to any future hot path added here.
- After this plan the remaining idle cost is dominated by the **ISR prologue**:
  ~25 cycles in + ~29 out to save 11 registers + SREG, because the tick can
  `ICALL` a user callback. `ASYNC_DELAY_DEFERRED_CALLBACKS=1` is the only lever
  that removes it (idle → ~32 cycles). Do not flip the default without asking;
  it changes when callbacks run.
- `_AD_TICK_SLOT(n)` still requires a literal `n`. A runtime-indexed caller
  silently reintroduces `__LSLW12` + `MUL` + `__GETW1P`.
- If `_async_next_target` ever stops being the exact minimum, §4.2's proof
  breaks and the unconditional recompute becomes merely wasteful (not wrong).
  Keep it unconditional regardless.
- A host-side test harness is still the largest missing safety net in this repo
  (see `plans/README.md` rejected findings).

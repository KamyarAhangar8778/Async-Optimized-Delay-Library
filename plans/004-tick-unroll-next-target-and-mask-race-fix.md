## 1. Why this plan exists

Plan 003 added `_async_active_mask` and made the tick visit only active slots.
Two defects came with it, and the hot path is still O(active slots) with two
expensive compiler helper calls per slot. Concretely:

1. **`start()` can steal a slot that is EXPIRED-but-not-yet-polled** — silent
   loss of a running timer (§4.1).
2. **The mask read-modify-write in `start()` / `cancel()` races the ISR** — a
   lost bit-clear leaves a dead slot marked ACTIVE, which fires one spurious
   callback (§4.2).
3. Every active slot costs ~78–93 cycles per tick because `1 << i` with a
   runtime `i` compiles to a **call to `__LSLW12`** (a bit-at-a-time shift
   loop) and the struct offset `i * 7` needs `MUL` + a `__GETW1P` call (§5).

The fix for (3) is to give the compiler compile-time slot indices, and then to
add an "earliest target" gate so a tick with N active slots and nothing due
costs the same as a tick with one (§7).

## 4. The two bugs — full analysis (read before touching code)

### 4.1 BUG-1: `start()` steals an EXPIRED slot

`async_delay.h:268` decides "free" purely from the mask bit. But a
**polling-mode slot that has expired** has its bit cleared and
`flags = ASYNC_SLOT_EXPIRED` (`async_delay.h:396`) — it is *allocated*, waiting
for the user's `async_delay_elapsed()`. `start()` sees the cleared bit, treats
the slot as free, and overwrites `target/duration/callback/flags`. The old
timer vanishes; the owner's `elapsed(old_id)` now returns 0 forever (or, worse,
returns 1 for the *new* timer's expiry and frees a slot it does not own).

Three slot states, only two mask values — the mask cannot distinguish
FREE from EXPIRED. That is the root cause.

**Reachable in the shipped test** (`async_delay_test.c`): `id_poll` (750 ms) and
`id_lcd` (200 ms) are both polling slots. The LCD refresh block runs many
`lcd_*` calls; if `id_poll` expires during that window, the next loop iteration
calls `elapsed(id_poll)` → frees slot, then `async_delay_start(750, 0)` scans
from index 0. If `id_lcd`'s slot has a lower index and is sitting EXPIRED at
that moment, `start` takes it. `id_lcd` then never reports elapsed and the LCD
freezes. It is timing-dependent, which is exactly why it has not been noticed.

Note the legacy path (`ASYNC_DELAY_OPT_BITMASK=0`) is **correct**, because it
tests `_AD_STATE(i) == ASYNC_SLOT_FREE`. So this is a regression from 003 only.

**Fix**: a second byte, `_async_used_mask` — bit n set ⟺ slot n is *allocated*
(ACTIVE **or** EXPIRED). `start()` allocates on `_async_used_mask`; the tick
walks `_async_active_mask`. Transitions:

| Event | `_async_used_mask` | `_async_active_mask` |
|-------|--------------------|----------------------|
| `start()` | set bit | set bit |
| tick, one-shot **with** callback fires | clear bit | clear bit |
| tick, polling (no callback) expires | **keep set** | clear bit |
| tick, periodic re-arms | keep set | keep set |
| `elapsed()` returns 1 | clear bit | (already clear) |
| `cancel()` | clear bit | clear bit |

Invariant to assert while tracing: `_async_active_mask & ~_async_used_mask == 0`
(never active without being allocated).

Bonus: allocation becomes "find the first zero bit of one byte" instead of a
per-slot load, which is *also* faster (§7.1).

### 4.2 BUG-2: mask RMW races the ISR

Plan 003 §"Concurrency" claims *"ISR never writes the mask, so no cli is needed"*.
False: `_async_delay_expire_slot()` is called **from the tick (ISR context)** and
writes the mask at `async_delay.h:385` and `async_delay.h:394` (and 416/424 in
the legacy ordering).

`_async_active_mask |= (1 << i)` and `&= ~(1 << i)` are **not** atomic on AVR;
CodeVisionAVR emits LDS → modify → STS. Confirmed in the generated asm at
`4887ce4`: `SUBOPT_0x6` is `LDS R26,__async_active_mask_G000`, `SUBOPT_0x0` is
`STS __async_active_mask_G000,R30`, and `start()` calls them at asm lines
1332–1334 — **after** the `sei` at asm line 1293. So the window is genuinely open.

Interleaving that loses a bit-clear:

```
main: start()  LDS mask        ; reads 0b0001 (slot 0 active)
  ISR:         slot 0 expires -> mask &= ~1 -> STS 0b0000
main:          OR  R30, 1<<1   ; 0b0001 | 0b0010 = 0b0011
main:          STS mask        ; writes 0b0011  <-- slot 0's clear is LOST
```

Slot 0 is now FREE (flags=0) but its bit is set. Next tick,
`_async_delay_expire_slot(0)` runs on a free slot; `_AD_CB(0)` was **never
cleared** on free (`async_delay.h:387` only writes flags), so the stale callback
pointer is still there and gets `ICALL`ed → **one spurious callback**, and if
`_AD_REPEAT` happens to be set it re-arms and keeps firing forever.

`cancel()` has the mirror-image race (its clear can lose an ISR's clear of a
*different* bit, or an ISR's re-arm).

**Fix**: every mask RMW in **main-loop context** (`start`, `cancel`, `elapsed`)
runs inside a critical section. Inside `_async_delay_expire_slot` no guard is
needed — it already runs with interrupts disabled in ISR context.

Use an **SREG save/restore**, not bare `cli`/`sei`:

```c
#define _ASYNC_ENTER_CRIT()  unsigned char _ad_sreg; \
                             _ad_sreg = SREG; #asm("cli")
#define _ASYNC_EXIT_CRIT()   SREG = _ad_sreg
```

CodeVisionAVR does not allow a declaration mid-block in C89-ish style reliably,
so declare `_ad_sreg` at the top of each function instead and make the macros
statement-only (see Phase 2 for the exact form). This also fixes a **latent
issue in the existing code**: `async_delay.h:280`'s unconditional `#asm("sei")`
turns interrupts *on* even if the caller had them off (e.g. `start()` called
from inside another critical section, or before `sei` in `main()`). Preserving
SREG is strictly more correct and costs ~2 cycles.

## 7. Design of the three optimizations

### 7.1 UNROLL_TICK — kill `__LSLW12`, `MUL` and `__GETW1P`

The whole per-slot cost in §5 exists because `i` is a **runtime** value:
`1 << i` becomes `RCALL __LSLW12` (a shift loop!), `&_async_slots[i]` becomes
`i * 7` via `MUL`, and loading `.target` goes through `RCALL __GETW1P`.

Give the compiler a **literal** index and all three vanish: `1 << 2` folds to
`4` (→ `SBRS R17,2`), `&_async_slots[2].target` folds to an absolute address
(→ `LDS`/`LDS`), and the bit to clear is passed in as a literal too.

```c
// Per-slot tick body with a COMPILE-TIME constant index n.
// clr = ~(1<<n), also a compile-time literal.
#define _AD_TICK_SLOT(n)                                                     \
    if (_ad_m & (unsigned char)(1u << (n)))                                  \
    {                                                                        \
        if ((async_tick_t)(_ad_now - _AD_TARGET(n)) < _ASYNC_HALF_RANGE)      \
            _async_delay_expire_slot((unsigned char)(n),                     \
                                     (unsigned char)~(1u << (n)));           \
    }
```

Then the tick is a chain of `#if ASYNC_DELAY_MAX_SLOTS > k` guarded invocations
for n = 0..7. No loop, no bit-search, and **no `m &= ~(1<<i)`** — each bit is
tested exactly once, so clearing the local copy is pointless work.

`_async_delay_expire_slot` also takes the precomputed `clr` mask so its own
`~(1<<i)` disappears from the sub-call.

Expected: per active-not-due slot **~72 → ~13 cycles**.

### 7.2 NEXT_TARGET — O(N) → O(1) per tick

One extra `async_tick_t`, `_async_next_target` = the earliest `target` among
ACTIVE slots (earliest in the wrap-safe sense: `a` is earlier than `b` iff
`(async_tick_t)(b - a) < _ASYNC_HALF_RANGE`). Well-defined here **because** the
library already requires every delay < half the range (ARCHITECTURE.md §6.1).

The tick becomes:

```c
_ad_now = (async_tick_t)(_async_tick_counter + 1);   /* one read, one write */
_async_tick_counter = _ad_now;
if (_async_active_mask == 0)
    return;
if ((async_tick_t)(_ad_now - _async_next_target) >= _ASYNC_HALF_RANGE)
    return;                       /* nothing is due yet — O(1) exit */
/* ... only now walk the slots (unrolled), then recompute _async_next_target */
```

The recompute is O(N) but runs **only on the ticks where something actually
expires** — plus in `start()` (cheap: one wrap-safe compare against the current
value, no scan) and in `cancel()` (full recompute, because the cancelled slot
might have been the minimum). For a 500 ms periodic on a 1 kHz tick that is 1
scan per 500 ticks.

`_ad_now` is also hoisted into a local, which removes the per-slot `LDS/LDS`
re-read of the volatile counter (4 cycles × N) — keep that even if
`NEXT_TARGET` is off.

**Sentinel handling**: when `_async_active_mask == 0` the value of
`_async_next_target` is irrelevant (the mask check returns first). Do **not**
invent an "invalid" sentinel — every tick-value is a legal target.

**Correctness rule (critical)**: `_async_next_target` must never be *later* than
the true minimum, or a slot fires late. It is safe for it to be *earlier* (just
costs one wasted walk). So: in `start()`, take the min unconditionally; in the
tick after expiry, do a full recompute; in `cancel()`, full recompute. Never
"optimize" by skipping the cancel recompute — that direction is the unsafe one.

Since the ISR reads `_async_next_target` (16/32-bit, non-atomic on AVR), all
main-context writes to it go inside the same critical section as the mask writes
(§4.2). This is why `FIX_ATOMIC_MASK` is a hard prerequisite of `NEXT_TARGET`
when `TIMER_BITS >= 16`; add that constraint `#if`.

### 7.3 DEFERRED_CALLBACKS — cut the 54-cycle ISR register spill

While the tick can `ICALL` a user callback, CodeVisionAVR must assume the
callback clobbers everything, so the ISR saves **11 registers + SREG** — 25
cycles in, 29 out, on *every* tick including idle ones (§5).

With `ASYNC_DELAY_DEFERRED_CALLBACKS=1` the ISR stops calling anything: on
expiry it sets a bit in `_async_pending_mask` and updates state, and the app
calls a new `async_delay_poll()` from the main loop, which drains the pending
mask and invokes the callbacks in **main context**.

```c
static void async_delay_poll(void)   /* MAIN context. Call from the main loop. */
{
    unsigned char p, i;
    _ASYNC_CRIT_DECL
    _ASYNC_ENTER_CRIT();
    p = _async_pending_mask;
    _async_pending_mask = 0;
    _ASYNC_EXIT_CRIT();
    if (p == 0) return;
    for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
        if (p & (unsigned char)(1u << i))
            if (_AD_CB(i) != (void *)0)
                _AD_CB(i)(i);
}
```

Trade-offs to state plainly in the header docs:
- **Win**: no `ICALL` in the ISR → the register save list collapses (expect
  ~3–5 registers) → idle tick ~86 → ~32 cycles. Callbacks may now use
  `delay_ms`, LCD, anything (they are no longer ISR code).
- **Cost**: callback latency = however long one main-loop iteration takes. If
  `async_delay_poll()` is never called, callbacks never fire. Two expiries of the
  same slot before one poll collapse into one call (a bit is a bit) — for a fast
  periodic with a slow main loop that means **dropped callbacks**, which is
  exactly why this is off by default.
- Periodic re-arm still happens in the ISR (phase-locked), so *timing* does not
  drift even if the callback is late.
- `MAX_SLOTS > 8` unsupported (8-bit pending mask) → `#error` above.

The final register-save list is decided by the compiler; the executor must read
it out of the fresh `.asm`/`.map` and report the real number, not this estimate.

### 7.4 Explicitly rejected (do NOT implement)

- **256-byte lowest-set-bit LUT** (floated in plan 003): pointless once the tick
  is unrolled — there is no bit search left. Do not add it.
- **8-byte `flash _async_bit[8]` table**: also unnecessary; the only remaining
  runtime-`i` shifts are in `cancel`/`elapsed` (cold paths, called from main).
  If a later measurement shows `cancel()` matters, revisit then.
- **Hand-written ASM for the tick**: rejected on maintainability. CodeVisionAVR
  mangles statics as `__async_slots_G000` / `__async_active_mask_G000`, and the
  `_G000` suffix depends on compilation order — brittle in a header-only library
  that users include from arbitrary translation units. The only real ASM win
  would be replacing the `CPI/LDI/CPC` compare against `0x7FFF` with a sign-bit
  test (`SBRC Rhi,7`), worth 2–3 cycles/slot — not worth the fragility.
- **Removing the `cli`/`sei` around the counter read**: correctness-critical
  (ARCHITECTURE.md §6.3, past bug `71e6924`). This plan *upgrades* it to
  SREG-preserving; it does not remove it.
- **Widening the mask past 8 bits**: out of scope; the `#error` guards it.

### Phase 2 — Critical-section macros + new state bytes

Right after `_ASYNC_HALF_RANGE` (`async_delay.h:240`) add:

```c
// ---------- Critical section (main context only) ----------
// SREG save/restore, NOT bare cli/sei: a bare sei would force interrupts ON
// even if the caller had them off (e.g. start() called before sei in main,
// or from inside another critical section).
#if ASYNC_DELAY_FIX_ATOMIC_MASK
#define _ASYNC_CRIT_DECL     unsigned char _ad_sreg;
#define _ASYNC_ENTER_CRIT()  do { _ad_sreg = SREG; #asm("cli") } while (0)
#define _ASYNC_EXIT_CRIT()   do { SREG = _ad_sreg; } while (0)
#else
#define _ASYNC_CRIT_DECL
#define _ASYNC_ENTER_CRIT()  #asm("cli")
```

**`_async_delay_start_common()`** (`async_delay.h:258`). Allocate from the
*used* mask, and do the counter read + all shared-state writes in one critical
section. Target shape:

```c
static unsigned char _async_delay_start_common(async_tick_t duration,
                                               async_delay_cb_t callback,
                                               unsigned char repeat)
{
    unsigned char i;
    unsigned char bit;
    async_tick_t now, tgt;
    _ASYNC_CRIT_DECL

#if ASYNC_DELAY_FIX_USED_MASK
    /* find the first slot whose ALLOCATED bit is clear */
    {
        unsigned char u = _async_used_mask;     /* single byte: atomic read */
        for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
            if ((u & (unsigned char)(1u << i)) == 0)
                break;
        if (i >= ASYNC_DELAY_MAX_SLOTS)
            return ASYNC_DELAY_NO_SLOT;
    }
#else
    for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
#if ASYNC_DELAY_OPT_BITMASK
        if ((_async_active_mask & (unsigned char)(1u << i)) == 0) break;
#else
        if (_AD_STATE(i) == ASYNC_SLOT_FREE) break;
#endif
    if (i >= ASYNC_DELAY_MAX_SLOTS)
        return ASYNC_DELAY_NO_SLOT;
#endif

    bit = (unsigned char)(1u << i);

    /* --- shared state: counter read + masks + next_target, one window --- */
    _ASYNC_SAVE_SREG();
    #asm("cli")
    now = _async_tick_counter;
    tgt = (async_tick_t)(now + duration);
    _AD_DUR(i)    = duration;
    _AD_TARGET(i) = tgt;
    _AD_CB(i)     = callback;
#if ASYNC_DELAY_OPT_MERGED_FLAGS
    _AD_FLAGS(i)  = (unsigned char)(ASYNC_SLOT_ACTIVE |
                                    (repeat ? ASYNC_FLAG_REPEAT : 0));
#else
    _AD_FLAGS(i)  = ASYNC_SLOT_ACTIVE;
#if ASYNC_DELAY_OPT_SPLIT_ARRAYS
    _async_repeat[i] = repeat;
#else
    _async_slots[i].repeat = repeat;
#endif
#endif
#if ASYNC_DELAY_OPT_NEXT_TARGET
    /* keep the earliest target; safe to be too early, never too late */
    if (_async_active_mask == 0 || _ASYNC_REACHED(_async_next_target, tgt))
        _async_next_target = tgt;
#endif
#if ASYNC_DELAY_FIX_USED_MASK
    _async_used_mask |= bit;
#endif
#if ASYNC_DELAY_OPT_BITMASK
    _async_active_mask |= bit;      /* LAST: slot fully built before visible */
#endif
    _ASYNC_REST_SREG();
    return i;
}
```

Read that `_async_next_target` condition carefully: `_ASYNC_REACHED(a, b)` is
"`b` is at or before `a`", so `_ASYNC_REACHED(_async_next_target, tgt)` means
"the new target is not later than the stored one" → adopt it. When no slot is
active the stored value is stale garbage, hence the `active_mask == 0` arm.
**Order matters**: this must be evaluated *before* `_async_active_mask |= bit`.

```c

// Recompute _async_next_target = earliest target among ACTIVE slots.
// CALLER MUST hold interrupts off (or be in ISR context).
static void _async_recompute_next(void)
{

}
#endif
```

### Phase 5 — The unrolled tick

Replace `async_delay_tick()` (`async_delay.h:435`–`493`) entirely. Keep the
legacy `#else` branch working.

```c
// Per-slot tick body. n MUST be a compile-time constant so that (1<<n),
// ~(1<<n) and &_async_slots[n] all fold to literals/absolute addresses —
// that is the whole point (no __LSLW12 call, no MUL, no __GETW1P).
#if ASYNC_DELAY_OPT_UNROLL_TICK
#define _AD_TICK_SLOT(n)                                                      \
    if (_ad_m & (unsigned char)(1u << (n)))                                   \
    {                                                                         \
        if (_ASYNC_REACHED(_ad_now, _AD_TARGET(n)))                            \
        {                                                                     \
            _async_delay_expire_slot((unsigned char)(n),                       \
                                     (unsigned char)~(1u << (n)));            \
            _ad_fired = 1;                                                    \
        }                                                                     \
    }
#endif

static void async_delay_tick(void)
{
#if ASYNC_DELAY_OPT_BITMASK
    async_tick_t  _ad_now;
    unsigned char _ad_m;
#if ASYNC_DELAY_OPT_NEXT_TARGET
    unsigned char _ad_fired;
#endif

    /* Counter first, ALWAYS — every early return below must not skip it,
       or delays drift whenever no slot is active. (Plan 003 trap.) */
    _ad_now = (async_tick_t)(_async_tick_counter + 1);
    _async_tick_counter = _ad_now;

    _ad_m = _async_active_mask;
    if (_ad_m == 0)
        return;                     /* idle tick */

#if ASYNC_DELAY_OPT_NEXT_TARGET
    if (!_ASYNC_REACHED(_ad_now, _async_next_target))
        return;                     /* nothing due yet: O(1) exit */
    _ad_fired = 0;
#endif

#if ASYNC_DELAY_OPT_UNROLL_TICK
    _AD_TICK_SLOT(0)
#if ASYNC_DELAY_MAX_SLOTS > 1
    _AD_TICK_SLOT(1)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 2
    _AD_TICK_SLOT(2)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 3
    _AD_TICK_SLOT(3)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 4
    _AD_TICK_SLOT(4)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 5
    _AD_TICK_SLOT(5)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 6
    _AD_TICK_SLOT(6)
#endif
#if ASYNC_DELAY_MAX_SLOTS > 7
    _AD_TICK_SLOT(7)
#endif
#else
    /* Not unrolled: runtime bit scan (pre-004 shape, kept for A/B). */
    {
        unsigned char i;
        for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
        {
            if (_ad_m & (unsigned char)(1u << i))
            {
                if (_ASYNC_REACHED(_ad_now, _AD_TARGET(i)))
                {
                    _async_delay_expire_slot(i, (unsigned char)~(1u << i));
#if ASYNC_DELAY_OPT_NEXT_TARGET
                    _ad_fired = 1;
#endif
                }
            }
        }
    }
#endif

#if ASYNC_DELAY_OPT_NEXT_TARGET
    if (_ad_fired)
        _async_recompute_next();    /* only on ticks where something expired */
#endif
#else
    /* Legacy: full linear scan, no mask. */
    unsigned char i;
    async_tick_t  _ad_now;
    _ad_now = (async_tick_t)(_async_tick_counter + 1);
    _async_tick_counter = _ad_now;
    for (i = 0; i < ASYNC_DELAY_MAX_SLOTS; i++)
    {
        if (_AD_STATE(i) == ASYNC_SLOT_ACTIVE)
        {
            if (_ASYNC_REACHED(_ad_now, _AD_TARGET(i)))
                _async_delay_expire_slot(i, (unsigned char)~(1u << i));
        }
    }
#endif
}
```

1. The counter increment stays the first statement (idle ticks must still count).

| T10 | `NEXT_TARGET` gate vs a slot armed with `duration = 0` | `tgt == now`; the very next tick has `_ad_now == now+1`, gate passes, slot fires (no lost immediate delay) |
| T11 | 2 slots, one due and one not | only the due one calls `expire_slot`; the other's target survives |
| T12 | `DEFERRED_CALLBACKS=1`: expiry then `poll()` | pending bit set in ISR, cb runs in main, bit cleared; a `cancel()` before `poll()` drops the owed cb |

T9 and T10 are the two that catch a wrong `_ASYNC_REACHED` polarity — do not skip
them.

### 9.2 Proteus regression (user-run)

`Simulation/AsyncTestSimulaion.pdsprj` covers: LED0 500 ms periodic callback,
LED1 750 ms polling, cancel test (must never fire), slot-overflow → `0xFF`,
LCD paced at 200 ms, and `loop_count` proving the main loop never blocks. All

## 12. Maintenance notes for whoever comes after

- **Concurrency contract after this plan**: `_async_active_mask`,
  `_async_used_mask`, `_async_pending_mask` and `_async_next_target` are shared.
  ISR (tick) writes active/pending/next_target; main (start/cancel/elapsed/poll)
  writes all four **inside a critical section**. Any new API that touches them
  must take the same section.
- **Invariant**: `_async_active_mask & ~_async_used_mask == 0`. A future host-side
  test harness should assert it after every operation, plus "idle tick still
  increments the counter" and "`_async_next_target` is never later than the true
  minimum ACTIVE target".
- `_AD_TICK_SLOT(n)` only works with a literal `n`. If someone later adds a
  runtime-indexed caller, they reintroduce `__LSLW12` and lose the whole win.
- Raising `MAX_SLOTS` past 8 requires widening all three masks to `unsigned int`
  and revisiting `_AD_TICK_SLOT` invocations; the `#error`s guard it today.
- The next real win after this plan is `DEFERRED_CALLBACKS` becoming the default
  — but only once the user is comfortable that callbacks no longer run in ISR
  context. Do not flip that default without asking.
- A host-side (PC) test harness remains the biggest missing safety net in this
  repo (noted as a rejected finding in `plans/README.md`); it would let T1–T12
  run automatically instead of by hand.
